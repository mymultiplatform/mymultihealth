# MyMultiHealth Store

Static storefront for `mymultihealth.com` focused on fast launch sales.

## Products
- Copper Toothbrush (`$19`)
- Smile Training Mouth Pad (`$29`)
- UV Tool Sanitizer Light (`$39`)

## What `index.html` includes
- Product cards with quantity selectors
- Cart with bundle discounts
- Quick bundle buttons (2-product and 3-product)
- Customer fields (name, email, phone, city, notes)
- Checkout by prefilled email (`mailto`)
- Copy-order-text fallback for DM/WhatsApp orders

## Wholesale
- `wholesale.html` includes 3 partner packs and a prefilled wholesale request flow.
- Pack pricing:
  - Pilot Pack (`$182`)
  - Growth Pack (`$349`)
  - Studio Pack (`$669`)

## Publish
This repo is configured for GitHub Pages with `CNAME` set to `mymultihealth.com`.
